Welford's Recurrences and the Sampling Mean and Variance of Hackers' Scores

30/10/2026

Exercise 1

Welford's Recurrence Formulas

Knuth's recurrence for the mean

Data often arrive as a stream $x_1, x_2, \dots$: log entries, packets, scores of attack attempts. We want the mean and the variance after every new value without storing the past values and without summing everything again. Let

$$M_k = \frac{1}{k}\sum_{i=1}^{k} x_i$$

be the mean of the first $k$ values. The sum of the first $k$ values is $kM_k$, and it is the sum of the first $k-1$ values plus the new one:

$$kM_k = (k-1)M_{k-1} + x_k = kM_{k-1} + (x_k - M_{k-1})$$

Dividing by $k$ gives Knuth's recurrence:

$$\boxed{M_k = M_{k-1} + \frac{x_k - M_{k-1}}{k}}, \qquad M_0 = 0$$

The new mean is the old mean corrected by a fraction $1/k$ of the innovation $x_k - M_{k-1}$, the surprise brought by the new value. Only $k$ and $M_{k-1}$ are stored, and no large sum $\sum x_i$ is ever formed. A consequence used below: since $kM_k - kM_{k-1} = x_k - M_{k-1}$,

$$x_k - M_k = (x_k - M_{k-1}) - (M_k - M_{k-1}) = \frac{k-1}{k}\,(x_k - M_{k-1})$$

Welford's recurrence for the sum of squares

The sum of squared deviations from the current mean is

$$S_k = \sum_{i=1}^{k} (x_i - M_k)^2 = \sum_{i=1}^{k} x_i^2 - kM_k^2$$

(expand the square and use $\sum_{i\le k} x_i = kM_k$). We follow the same idea as for the mean: write $S_k$ as $S_{k-1}$ plus a correction that only involves the new value and the stored means. Subtracting the same identity at step $k-1$:

$$S_k - S_{k-1} = x_k^2 - kM_k^2 + (k-1)M_{k-1}^2$$

From the mean recurrence, $(k-1)M_{k-1} = kM_k - x_k$, so $(k-1)M_{k-1}^2 = (kM_k - x_k)\,M_{k-1}$ and

$$\begin{aligned} S_k - S_{k-1} &= x_k^2 - x_kM_{k-1} - kM_k\,(M_k - M_{k-1}) \\ &= x_k\,(x_k - M_{k-1}) - M_k\,(x_k - M_{k-1}) && \text{since } k(M_k - M_{k-1}) = x_k - M_{k-1}\\ &= (x_k - M_{k-1})(x_k - M_k) \end{aligned}$$

This is Welford's recurrence:

$$\boxed{S_k = S_{k-1} + (x_k - M_{k-1})(x_k - M_k)} = S_{k-1} + \frac{k-1}{k}\,(x_k - M_{k-1})^2, \qquad S_0 = 0$$

The increment is the product of the deviation of $x_k$ from the old mean and from the new mean. Both factors have the same sign, so $S_k$ never decreases, as a sum of squares should; it is also invariant if every $x_i$ is shifted by a constant, because only differences appear.

Recurrence for the variance

The variance is the sum of squares divided by the number of degrees of freedom. The sampling variance uses $k-1$ (Bessel's correction, justified in Exercise 2), the population (or plug-in) variance uses $k$:

$$s_k^2 = \frac{S_k}{k-1}\ (k \ge 2), \qquad \hat\sigma_k^2 = \frac{S_k}{k}$$

Dividing Welford's recurrence by $k$ and writing $S_{k-1} = (k-1)\hat\sigma_{k-1}^2$ gives exactly the shape of Knuth's formula: the variance is a running average of the terms $(x_k - M_{k-1})(x_k - M_k)$, just as the mean is a running average of the $x_k$:

$$\boxed{\hat\sigma_k^2 = \hat\sigma_{k-1}^2 + \frac{(x_k - M_{k-1})(x_k - M_k) - \hat\sigma_{k-1}^2}{k}}$$

Dividing by $k-1$ instead, with the second form of the recurrence:

$$\boxed{s_k^2 = \frac{k-2}{k-1}\,s_{k-1}^2 + \frac{(x_k - M_{k-1})^2}{k}}, \qquad k \ge 2,\ s_1^2 \text{ undefined}$$

The code

The state is three numbers, $k$, $M$ and $S$. Each new value costs one subtraction, one division, one multiplication: the core is three lines.

const delta = x - mean;        // x_k - M_{k-1}
mean += delta / k;             // Knuth:   M_k = M_{k-1} + (x_k - M_{k-1}) / k
ss += delta * (x - mean);      // Welford: S_k = S_{k-1} + (x_k - M_{k-1})(x_k - M_k)

The complete accumulator, used by all the simulations on this page (welford.js):

class Welford {
  constructor() {
    this.k = 0;
    this.mean = 0;
    this.ss = 0;
  }

  push(x) {
    this.k += 1;
    const delta = x - this.mean;
    this.mean += delta / this.k;
    this.ss += delta * (x - this.mean);
    return this;
  }

  get variance() { return this.k > 1 ? this.ss / (this.k - 1) : NaN; }  // s^2
  get populationVariance() { return this.k > 0 ? this.ss / this.k : NaN; }
}

The same in Python:

class Welford:
    def __init__(self):
        self.k, self.mean, self.ss = 0, 0.0, 0.0

    def push(self, x):
        self.k += 1
        delta = x - self.mean
        self.mean += delta / self.k
        self.ss += delta * (x - self.mean)

    @property
    def variance(self):
        return self.ss / (self.k - 1) if self.k > 1 else float("nan")

The order matters: delta is computed with the old mean, the last line uses the new one, so the product is $(x_k - M_{k-1})(x_k - M_k)$.

Step-by-step trace

Every row is one call of push. The last row agrees with the mean and variance computed from the whole list at once.

Why not simply $\sum x^2 - (\sum x)^2/n$?

The textbook one-pass formula $s^2 = \left(\sum x_i^2 - (\sum x_i)^2/n\right)/(n-1)$ also needs only running sums, but it subtracts two huge, nearly equal numbers. In double precision (about 16 significant digits) the difference loses all its digits when the mean is large compared with the spread: catastrophic cancellation. The two-pass formula is accurate but needs to store the data. Welford's recurrence works on deviations from the running mean, which stay of the size of the spread, so it is one-pass and stable.

In practice this matters for timestamps, byte counters or sensor readings with a large baseline: summing their squares overflows the precision long before the values themselves do.

Exercise 2

Sampling Mean and Variance

The model

In Homework 3 each penetration attempt was a success or a failure. Here each attempt receives a score between 0 and 10. The default distribution extends the Bernoulli model: every system is protected by 10 independent security controls (firewall, authentication, patching, …), each one broken with probability $p$, and the score is the number of controls the hacker gets through:

$$X = \sum_{\ell=1}^{10} B_\ell,\quad B_\ell \sim \operatorname{Bernoulli}(p) \quad\Longrightarrow\quad X \sim \operatorname{Bin}(10, p),\qquad \mu = 10p,\quad \sigma^2 = 10p(1-p)$$

With $p = 0.3$: $\mu = 3$, $\sigma^2 = 2.1$. Two other distributions can be selected for comparison: the discrete uniform on $\{0, \dots, 10\}$ ($\mu = 5$, $\sigma^2 = 10$) and the continuous uniform on $[0, 10]$ ($\mu = 5$, $\sigma^2 = 100/12 \approx 8.33$).

There are $m$ hackers, each attacking $n$ systems, so hacker $j$ produces a trajectory $X_1^{(j)}, \dots, X_n^{(j)}$ of i.i.d. scores. Each hacker feeds the scores to its own Welford accumulator and obtains

$$\bar X^{(j)} = M_n^{(j)}, \qquad s^{2\,(j)} = \frac{S_n^{(j)}}{n-1}, \qquad j = 1, \dots, m$$

and across the hackers we compute the averages $\frac1m\sum_j \bar X^{(j)}$ and $\frac1m\sum_j s^{2\,(j)}$, to be compared with $\mu$ and $\sigma^2$.

What theory predicts

The sampling mean

By linearity and independence,

$$E[\bar X] = \frac1n\sum_{i=1}^n E[X_i] = \mu, \qquad \operatorname{Var}(\bar X) = \frac{1}{n^2}\sum_{i=1}^n \operatorname{Var}(X_i) = \frac{\sigma^2}{n}$$

$\bar X$ is an unbiased estimator of $\mu$ and its standard deviation, the standard error, is $\sigma/\sqrt n$.

The sampling variance and Bessel's correction

Adding and subtracting $\mu$ inside the sum of squares:

$$S_n = \sum_{i=1}^n (X_i - \bar X)^2 = \sum_{i=1}^n (X_i - \mu)^2 - n(\bar X - \mu)^2$$

Taking expectations, $E[(X_i - \mu)^2] = \sigma^2$ and $E[(\bar X - \mu)^2] = \operatorname{Var}(\bar X) = \sigma^2/n$, so

$$E[S_n] = n\sigma^2 - \sigma^2 = (n-1)\sigma^2 \quad\Longrightarrow\quad E[s^2] = E\left[\frac{S_n}{n-1}\right] = \sigma^2, \qquad E\left[\frac{S_n}{n}\right] = \frac{n-1}{n}\,\sigma^2$$

The deviations are measured from $\bar X$, which is fitted to the same data and is therefore closer to them than $\mu$: $S_n$ is systematically too small by one $\sigma^2$. One degree of freedom is spent on estimating the mean, and dividing by $n-1$ compensates exactly. The spread of $s^2$, with $\mu_4 = E[(X-\mu)^4]$, is

$$\operatorname{Var}(s^2) = \frac1n\left(\mu_4 - \frac{n-3}{n-1}\,\sigma^4\right) \approx \frac{\mu_4 - \sigma^4}{n}$$

so it also decreases like $1/n$, with a constant that depends on the tails of the distribution (its kurtosis).

Averaging over the $m$ hackers

The $m$ hackers are $m$ independent repetitions of the same experiment, so the averages over hackers estimate the expectations above, with errors that shrink like $1/\sqrt m$:

$$\frac1m\sum_{j=1}^m \bar X^{(j)} \approx \mu \pm \frac{\sigma}{\sqrt{mn}}, \qquad \frac1m\sum_{j=1}^m s^{2\,(j)} \approx \sigma^2 \pm \sqrt{\frac{\operatorname{Var}(s^2)}{m}}$$

The histogram of the $m$ values of $\bar X^{(j)}$ is an empirical picture of the sampling distribution of $\bar X$, and the same for $s^2$.

Simulation

Every hacker attacks $n = 1000$ systems; since Welford's algorithm is online, the sampling mean and variance after $n = 2, 5, 10, 30, 100, 1000$ systems are read from the same accumulator while the scores stream in.

Each line is the output of one Welford accumulator after every system. At the start the estimates jump around (one score can move the mean by up to $10/k$), then they settle inside a band that narrows like $1/\sqrt k$.

Averages across hackers and the effect of $n$

On log-log axes both spreads fall on straight lines of slope $-1/2$: multiplying the number of systems by 100 makes the sampling means and the sampling variances 10 times more precise.

Conclusions

What the comparisons show

  • The average of the sampling means equals $\mu$ for every $n$, even $n = 2$: $\bar X$ is unbiased. The residual difference is of order $\sigma/\sqrt{mn}$ and disappears as more hackers are added.
  • The average of the sampling variances equals $\sigma^2$, again for every $n$, because $s^2$ divides by $n-1$. The column $S_n/n$ instead stays below $\sigma^2$ by the factor $(n-1)/n$: at $n = 2$ it is half of $\sigma^2$, at $n = 1000$ the bias is negligible. The simulation confirms Bessel's correction.
  • A single hacker is not the average. Each individual $\bar X^{(j)}$ and $s^{2\,(j)}$ can be far from $\mu$ and $\sigma^2$, especially for small $n$; unbiasedness is a property of the estimator on average over repetitions, which is exactly what the $m$ hackers reproduce.

Why this is useful in inferential statistics

  • In reality $\mu$ and $\sigma^2$ of the attack scores are unknown: an analyst sees one trajectory of $n$ scores and must estimate them. The experiment shows that $\bar X$ and $s^2$ hit the right targets on average and that their error is predictable, $\sigma/\sqrt n$ and $\sqrt{\operatorname{Var}(s^2)}$.
  • Because $s^2$ is unbiased for $\sigma^2$, $s/\sqrt n$ is a usable estimate of the standard error of $\bar X$. Together with the Central Limit Theorem (the histogram of $\bar X$ follows $N(\mu, \sigma^2/n)$), this gives confidence intervals $\bar X \pm 1.96\,s/\sqrt n$ and hypothesis tests on the mean, for example whether a patch has lowered the average penetration score. The coverage column checks this: the interval contains $\mu$ about 95% of the time once $n$ is moderately large; for very small $n$ it covers less, which is why Student's $t$ quantile with $n-1$ degrees of freedom replaces 1.96.
  • The $n-1$ that appears in $s^2$ is the same $n-1$ degrees of freedom of the $t$ and $\chi^2$ distributions used in these procedures.
  • Welford's recurrences make all of this available online: a monitoring system can keep $k$, $M_k$ and $S_k$ for each host or user and update the mean, the variance and a confidence interval at every event, without storing the history and without numerical trouble.

Effect of the number of systems $n$

  • Increasing $n$ does not change the centre of the sampling distributions (they are unbiased for every $n$), it reduces their spread: $\operatorname{sd}(\bar X) = \sigma/\sqrt n$ and $\operatorname{sd}(s^2) \approx \sqrt{(\mu_4 - \sigma^4)/n}$, both of order $1/\sqrt n$. Both estimators are consistent: they converge to $\mu$ and $\sigma^2$ (Law of Large Numbers).
  • The shape changes too. For small $n$ the sampling means take few values and the sampling variances are strongly right-skewed (many hackers get a small $s^2$, a few a very large one; for $n = 2$, $s^2 = (X_1 - X_2)^2/2$ is often 0). As $n$ grows both histograms become symmetric and close to normal.
  • The variance estimate is noisier than the mean estimate: its relative error $\operatorname{sd}(s^2)/\sigma^2 \approx \sqrt{(\kappa + 2)/n}$, with $\kappa$ the excess kurtosis, is about $\sqrt{2/n}$, so estimating the variability of an attacker requires more attempts than estimating their average score.
